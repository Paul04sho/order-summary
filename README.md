## Présentation

### Le défi

Les utilisateurs doivent être capables de :

- Voir les états de survol (hover) pour tous les éléments interactifs de la page.
- Voir une mise en page optimisée selon la taille de l'écran de leur appareil (Mobile / Desktop).
